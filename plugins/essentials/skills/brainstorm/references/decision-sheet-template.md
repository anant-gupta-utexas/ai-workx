# How to run this sheet

Identify which entries are real decisions (usually 3–5) and spend the time there; everything else ticks through.

When a decision can't be made fast, write down what information would unblock it. Don't stall — note it, move on, circle back.

When every entry is answered, fill the summary table and pick the first concrete action that the locked decisions enable.
